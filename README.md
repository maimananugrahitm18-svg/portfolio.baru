# Portofolio Profesional Web Developer - Laravel & Fullstack

Portofolio web developer modern berstandar industri khusus untuk ekosistem **PHP & Laravel**. ## 🚀 Cara Menjalankan Portofolio

### Opsi 1: Menggunakan PHP Built-in Server (Rekomendasi)
Buka terminal / PowerShell di direktori ini, lalu jalankan:
```bash
php -S 127.0.0.1:8000
```
Buka browser dan akses: [http://127.0.0.1:8000](http://127.0.0.1:8000)

### Opsi 2: Buka Langsung File HTML
Anda dapat langsung mengklik dua kali file `index.html` untuk membukanya di browser apa pun (Google Chrome, Microsoft Edge, Firefox, Safari).

## 🎨 File & Direktori
- `index.html`: Berkas HTML utama dengan struktur semantik, SEO-friendly, dan aksesibilitas lengkap.
- `css/style.css`: Desain kustom berstandar developer modern (blueprint grid background, glassmorphism, browser chrome mockup, CSS variables, dark/light theme, responsive grid).
- `js/main.js`: Logika interaktif (Interactive Artisan CLI, API console tester, architecture pipeline switcher, theme toggle, project filter, modal popup, certificate lightbox, command palette `Ctrl+K`, GitHub heatmap generator, ticker realtime).
- `assets/images/`: Tangkapan layar proyek beresolusi tinggi, foto profil, dan dokumen sertifikat.
- `assets/certificates/`: Berkas PDF sertifikat resmi yang siap diunduh.
